## 页面布局

### 管理员登录 (`/login`)

- 布局：全屏最小宽度 1280px，页面使用 var(--color-background)；顶部左侧放置产品名称，主体为水平垂直居中的单列表单面板。面板宽 400px、内边距 32px、背景 var(--color-surface)、1px 边框 var(--color-border)、圆角 8px、轻阴影；标题与表单间距 24px，字段垂直间距 16px，按钮占满内容宽度且高 40px。登录页不显示后台侧栏；已登录访问时直接跳转 /products。
- 组件：产品标识：左上距视口 32px，字号 20px，字重 600、登录表单：账号与密码字段，标签位于控件上方 6px、文本输入框：宽 100%，高 40px，水平内边距 12px，边框 1px，圆角 6px、密码框：右侧 36px 区域放置显示或隐藏密码图标按钮，并提供 tooltip、登录按钮：宽 100%，高 40px，主色实底、认证错误提示：表单顶部内联警示条，不暴露账号是否存在、主题切换图标按钮：右上角 36px × 36px
- 状态：初始态：登录按钮可用，字段为空时不预先显示错误、加载态：登录按钮显示 16px 加载图标和“登录中”，账号与密码不可编辑，禁止重复提交，面板尺寸不变化、字段错误态：失焦或提交后在字段下方显示 13px 危险色文本，输入框使用危险色边框；修正后重新校验并清除、认证错误态：在表单顶部显示“账号或密码错误”或“账号已禁用”，保留账号，清空密码并聚焦密码框、接口错误态：显示“登录失败，请稍后重试”的警示条，保留输入内容并恢复提交能力、会话失效态：由管理页跳转而来时，在表单上方显示“登录状态已失效，请重新登录”信息提示

### 商品列表 (`/products`)

- 布局：固定左侧导航 208px + 主工作区。侧栏高度 100vh、位置 fixed；主工作区 margin-left:208px，顶部栏高 56px，内容区内边距 24px 32px，最大内容宽度不限制。页面标题行高 40px；其下 16px 为筛选工具栏，再下 16px 为无外层卡片嵌套的数据表格。表格最小宽度 920px，容器宽度 100%，在 1280px 以上不得产生页面级横向滚动；列建议为主图 72px、名称 minmax(220px,1fr)、售价 120px、库存 120px、状态 100px、更新时间 168px、操作 220px。分页栏高 56px，右对齐。
- 组件：固定侧栏：产品名称、商品管理、订单管理；当前项使用主色浅背景和左侧 3px 指示条、顶部栏：页面面包屑、主题切换、管理员名称、退出按钮、标题与主操作行：左侧“商品管理”，右侧带加号图标的“新建商品”按钮、筛选工具栏：宽 280px 商品名称搜索框、160px 状态选择器、查询按钮、重置按钮、商品表格：44px 表头、64px 数据行、单元格水平内边距 12px、行分隔线 1px、商品主图：48px × 48px，object-fit:cover，圆角 4px；加载失败显示占位图标、金额：使用等宽数字特性 tabular-nums，右对齐，固定两位小数、库存：使用 tabular-nums；库存为 0 时使用危险色文本、状态标签：上架为成功色、下架为中性色，高 24px，圆角 4px、行操作：编辑为文字按钮；库存调整为图标加文字按钮；上架或下架按当前状态显示、库存调整对话框：宽 420px，包含当前库存、整数输入框、取消与保存按钮、分页器：总条数、上一页、页码、下一页和每页 20/50 条选择器
- 状态：加载态：保留筛选工具栏；表格显示 8 行骨架，列宽固定，分页区显示骨架且不可操作、首次空态：表格区域最小高度 320px，显示商品图标、“暂无商品”和“新建商品”按钮、筛选空态：显示“未找到符合条件的商品”和“清除筛选”按钮，不显示新建引导、错误态：表格区域显示错误图标、“商品加载失败”和“重试”按钮；不得残留过期或局部数据、库存保存态：对话框保存按钮显示加载，关闭与输入操作禁用；成功后关闭对话框并刷新对应行、库存保存失败态：对话框保持打开并保留输入，字段上方显示错误；列表继续显示服务端原库存、上下架加载态：仅当前行操作禁用并显示小型加载图标，不阻塞其他行、零库存上架态：上架按钮禁用，悬停或聚焦显示“库存为 0，无法上架”、上下架失败态：保持原状态，页面右上显示可关闭错误通知、会话失效态：停止请求并跳转 /login，不继续展示管理数据

### 商品创建与编辑 (`/products/new 和 /products/:id/edit`)

- 布局：沿用 208px 固定侧栏与 56px 顶部栏。内容区内边距 24px 32px，页面标题行包含返回按钮、标题和模式说明。表单最大宽度 960px，不使用浮动卡片；以 1px 顶部分隔线划分“基本信息”和“销售与库存”两个区块。桌面采用 label 160px + control minmax(360px,640px) 的两列网格，行间距 20px。主图 URL 与预览并排，预览固定 160px × 160px。底部操作栏 position:sticky，bottom:0，高 64px，背景 var(--color-surface)，上边框 1px，按钮右对齐；确保长描述滚动时始终可保存。
- 组件：返回按钮：左箭头图标加“返回商品列表”、页面标题：新建模式显示“新建商品”，编辑模式显示“编辑商品”、商品名称输入框：最大长度 200，宽 560px、主图 URL 输入框：最大长度 2048，支持 http 或 https 校验、图片预览：160px × 160px，object-fit:cover，圆角 6px，带 1px 边框、售价输入框：宽 240px，前缀“¥”，step=0.01，使用 tabular-nums、库存输入框：宽 240px，step=1，使用 tabular-nums、商品描述文本域：宽 640px，最小高 144px，可垂直调整，显示字符计数、字段标签：必填项附危险色星号，并通过可访问文本标记 required、取消按钮：次级样式，返回列表、保存按钮：主色样式，新建时为“创建商品”，编辑时为“保存修改”、页面级错误警示条：位于表单标题下方，用于保存或加载失败
- 状态：新建初始态：字段为空，商品状态说明显示“创建后默认为下架”、编辑加载态：标题可见，表单区域显示与字段布局一致的骨架，保存按钮禁用、编辑加载失败态：不展示残缺表单，显示“商品信息加载失败”、重试和返回列表按钮、字段错误态：名称或主图为空、URL 非 http/https、售价小于等于 0 或超过两位小数、库存小于 0 或非整数时，在字段下方就近显示错误；首个无效字段自动聚焦、图片加载态：预览区显示居中加载图标；加载失败显示图片占位图和“图片无法加载”，URL 内容保持不变、保存态：保存按钮显示加载图标与“保存中”，所有字段和离开操作禁用，禁止重复提交、保存成功态：显示短暂成功通知并返回 /products，列表以服务端结果为准、保存失败态：保留全部表单输入，恢复操作能力，在页面级警示条显示失败原因，不更新本地持久化状态、未保存离开态：字段发生变化后点击返回、取消或导航项时，显示确认对话框；无修改时直接离开、会话失效态：跳转 /login，不缓存密码类数据；商品草稿仅保留在当前页面内存中

- 组件：固定侧栏：商品管理、订单管理；订单管理为当前项、顶部栏：页面面包屑、主题切换、管理员名称和退出按钮、订单号搜索框：宽 320px，提示输入完整订单号，回车可查询、订单状态筛选器：宽 180px，选项为全部、待付款、待发货、已发货、已完成、已取消、查询与重置按钮、订单表格：表头高 44px，数据行高 56px，行悬停显示弱背景、订单号：等宽字体，可选中复制，默认完整显示、订单金额：右对齐、tabular-nums、固定两位小数、状态标签：待付款使用警告色，待发货使用主色，已发货使用信息色，已完成使用成功色，已取消使用中性或危险弱色、查看详情按钮：右箭头图标加文字、分页器：总条数、上一页、页码、下一页和每页 20/50 条选择器

## 交互说明

- 全局仅针对宽度 1280px 及以上桌面端设计；应用壳使用 min-width:1280px，内容列使用 minmax(0,1fr)，表格不得造成页面级横向溢出。
- 默认使用浅色主题；通过 [data-theme="dark"] 覆盖同名语义变量。主题选择写入本地存储，首次访问跟随 prefers-color-scheme；切换不刷新页面。
- 所有控件使用 box-sizing:border-box；输入框和默认按钮高 36px，主表单关键按钮可高 40px，图标按钮固定 36px × 36px，圆角统一 6px，卡片或对话框最大圆角 8px。
- 推荐间距基于 4px 网格：4、8、12、16、20、24、32px；页面区块间距 24px，字段间距 20px，按钮组间距 8px。
- 主要按钮使用 var(--color-primary) 背景；悬停切换为 --color-primary-hover，按下切换为 --color-primary-active。次级按钮使用透明背景和 --color-border 边框，悬停使用 --color-surface-muted。
- 危险操作使用危险色边框或文字；只有确认对话框中的最终取消操作使用危险色实底，避免页面同时出现多个高强调按钮。
- 所有可交互元素必须提供 :focus-visible 状态：outline:none；box-shadow:0 0 0 3px var(--color-focus-ring)；边框同时切换为 var(--color-primary)。
- 禁用控件使用 --color-disabled-background 和 --color-disabled-foreground，cursor:not-allowed，opacity 不低于 0.72；禁用原因不能仅依赖颜色，应提供 tooltip 或就近说明。
- 表格行悬停使用 var(--color-surface-muted)，不改变行高；键盘聚焦行内操作时同样显示弱背景。操作列固定在右侧视觉边界，不因按钮加载文本变化而移动。
- 表格金额、库存、数量、日期数字使用 font-variant-numeric:tabular-nums；金额统一显示人民币符号和两位小数，日期显示本地时区 YYYY-MM-DD HH:mm:ss。
- 搜索框按 Enter 提交；点击查询、修改筛选器或清除条件后页码重置为 1。搜索值提交前去除首尾空格，商品名称允许模糊查询，订单号仅完整精确查询。
- 分页切换后保留筛选条件并将主内容区滚动到表格顶部；请求期间分页按钮禁用，响应顺序异常时只采用最后一次请求结果。
- 表单在首次提交或字段失焦后校验；错误文字位于字段下方 4px，高度至少 20px，避免错误出现时大幅布局跳动。提交失败不得清空输入。
- 必填错误文案应具体，例如“请输入商品名称”“售价必须大于 0”“库存必须为大于等于 0 的整数”，不得只显示“格式错误”。
- 数字输入禁止使用滚轮意外修改；售价最多两位小数，库存只接受十进制整数。提交时再次规范化并依赖服务端最终校验。
- 保存、发货、取消和登录请求期间禁用对应提交按钮并显示 16px 加载图标；按钮保留固定最小宽度，防止文字变化引发布局位移。
- 乐观更新仅用于非持久视觉反馈；商品库存、上下架、订单状态和备注均以服务端成功响应为准。失败时恢复服务端原值，不显示未保存结果。
- 成功通知默认 3 秒自动关闭；错误通知默认 6 秒且可关闭。与具体字段相关的错误必须同时就近展示，toast 不能替代字段错误。
- 对话框打开后焦点进入首个可操作字段，Tab 焦点限制在对话框内；Escape 仅在未提交时关闭；关闭后焦点返回触发按钮。
- 取消订单等不可逆操作必须二次确认；确认按钮默认不自动获得焦点，避免回车误触。并发导致状态不允许时刷新订单详情。
- 导航离开存在未保存表单或备注时弹出确认对话框；保存成功后清除 dirty 状态。浏览器刷新或关闭页面时使用 beforeunload 标准提示。
- 图片使用 object-fit:cover；加载失败显示中性色占位图标和可读替代文本，不显示破损图片。图片预览不得因原图比例改变布局。
- 状态不可只靠颜色表达，所有状态标签必须包含文字。状态文案固定映射：pending_payment 为“待付款”、pending_shipment 为“待发货”、shipped 为“已发货”、completed 为“已完成”、cancelled 为“已取消”。
- 图标优先使用 Lucide，默认 16px，纯图标按钮必须提供 aria-label 和悬停 tooltip；常规命令使用图标加文字，避免难以识别的自定义符号。
- 退出操作点击后立即禁用入口并调用退出接口；无论服务端响应是否成功都清理本地会话凭据并跳转 /login。受保护接口返回未认证状态时统一执行会话失效流程。
- 正文与背景、按钮文字与按钮背景需满足 WCAG AA 对比度；深色主题中边框、状态底色和悬停背景必须使用对应深色覆盖变量，不直接复用浅色背景。
- 动画时长使用 120ms 至 180ms ease-out，仅用于颜色、边框、阴影和透明度；骨架使用低对比度脉冲。prefers-reduced-motion:reduce 时关闭非必要动画。
- 长商品名称最多显示两行并省略，悬停显示完整 tooltip；地址和留言允许换行；订单号与运单号不省略并提供复制操作，复制成功显示轻量提示。
